# 📰 News Trend Analysis using Apache Spark and Kafka

A Big Data Framework (BDF) capstone project that analyzes large-scale news datasets using **Apache Spark** and **Apache Kafka**. The project demonstrates data preprocessing, real-time data streaming, and trend analysis to uncover meaningful insights from news articles.

---

## 📌 Project Overview

This project leverages Apache Spark for distributed data processing and Apache Kafka for real-time data streaming to analyze large volumes of news data efficiently. It identifies trends based on publication dates, news categories, and sources while providing valuable analytical insights.

---

## 🎯 Objectives

- Analyze large-scale news datasets.
- Process data using Apache Spark.
- Integrate Apache Kafka for real-time data streaming.
- Identify news publishing trends over time.
- Perform category-wise and source-wise news analysis.
- Generate visualizations for better understanding of news patterns.

---

## ✨ Features

- News data preprocessing

## 🚀 How to Run

1. Clone or download this repository.
2. Install Python and Jupyter Notebook.
3. Install Apache Spark.
4. Install Apache Kafka.
5. Open `BDF_KAFKA_INTEGRATION.ipynb`.
6. Execute the notebook step by step.
